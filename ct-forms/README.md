# CT Forms (Clean Build)

A professional, drag-and-drop WordPress form builder designed for stability and high-fidelity layouts.

## Features
* **10-Field Library**: Includes Dropdowns, Checkboxes, File Uploads, US States, and more.
* **Triple-Tab Comms**: Integrated Notification emails, Autoresponders, and Success Message logic.
* **Live Designer**: Real-time drag-and-drop canvas with a Hero Title bar.
* **Mobile Ready**: Frontend forms use clean, responsive CSS.

## Installation
1. Upload the `ct-forms` folder to your `/wp-content/plugins/` directory.
2. Activate the plugin through the 'Plugins' menu in WordPress.
3. Navigate to **CT Forms** in the admin sidebar to create your first form.

## Usage
To display a form on any page or post, use the provided shortcode:
`[ct_form id="YOUR_FORM_ID"]`
