\# Changelog



All notable changes to this project will be documented in this file.



\## \[6.1.0] - 2026-02-02

\### Removed

\- \*\*Conditional Logic Engine\*\*: Stripped all "Smart Visibility" code from the builder and frontend to ensure 100% field visibility and stability.

\- \*\*Logic Mapping\*\*: Removed sanitized label-to-slug mapping that caused front-end naming conflicts.



\### Fixed

\- \*\*Dropdown Field Restoration\*\*: Fixed a UI bug where the Dropdown field disappeared from the sidebar library.

\- \*\*Communication Tabs\*\*: Restored the Notifications, Autoresponder, and Success Logic tabs in the builder settings.



\## \[5.0.0] - \[Previous]

\### Added

\- Experimental "Universal ID Bridge" for smart visibility.

\- Initial implementation of the 10-field library.
